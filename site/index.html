Aguardando texto…

As 120 palavras de conteúdo mais frequentes. Clique numa palavra para buscá-la no texto.

    Os modelos rodam localmente com Transformers.js (WebAssembly). No primeiro uso o navegador baixa o modelo, que depois fica em cache.

    Gênero textual

    Classificação zero-shot por similaridade semântica com descrições de cada gênero (modelo MiniLM multilíngue, ~118 MB).

    Sentimento

    Polaridade de cada frase (modelo DistilBERT multilíngue, ~136 MB). Até 200 frases, amostradas ao longo do texto.

    Extrai as expressões mais representativas usando TF-IDF entre frases + re-ranking MMR para diversidade. Zero latência — sem modelo de IA.

    Detecta pessoas, locais e organizações usando BERT multilingual (modelo NER ~185 MB, baixado na primeira vez). Analisa os primeiros 2000 caracteres.

    Gera um relatório HTML completo com todas as análises realizadas nesta sessão. O arquivo é gerado localmente no seu navegador.

    Execute as análises desejadas (resumo, frases-chave, sentimento, entidades) antes de exportar para incluí-las no relatório.
